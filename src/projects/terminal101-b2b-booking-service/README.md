# Terminal101 (B2B Booking Service)

B2B flight and hotel booking platform built for travel-agency workflows.

- **Period:** 2022 – 2025-12
- **Relationship:** built at MIROTECH GROUP

## Overview

Terminal101 is the B2B counterpart to Tadilo: a flight and hotel booking platform aimed at travel agencies rather than consumers. Agencies could work through dedicated access/accounts with different pricing arrangements, which shaped the workflows around agency operations instead of a single customer journey. It shares core booking and search challenges with Tadilo — real-time provider results, large result sets, filtering, sorting, and pagination — handled in the context of agency-facing workflows.

## Responsibilities & Contributions

- Worked on the booking and search experience for travel-agency workflows, including flight and hotel search with filtering, sorting, and pagination
- Handled real-time, incremental provider data over WebSocket with client-side accumulation of incoming results
- Worked with large result sets client-side so the interface stayed responsive while results arrived
