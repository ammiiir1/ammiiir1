# Easybestell (Admin Panel)

Admin panel to manage staff, couriers, customers, reports and more in the Easybestell project.

- **Period:** 2023 – 2024
- **Relationship:** built at MIROTECH GROUP

## Overview

The admin panel is part of the broader Easybestell restaurant ordering and operations platform, alongside the online ordering app for customers and the restaurant management app. Five frontend developers worked across the ecosystem, with different developers owning different areas. A notable shared challenge was automatic ticket printing (see the restaurant management app record): the platform's automatic printing used a local Electron printing bridge, and I contributed to that architecture and its frontend integration.

## Responsibilities & Contributions

- Frontend development on the admin panel within the shared Easybestell platform
- Contributed to the automatic ticket-printing architecture and its frontend integration
