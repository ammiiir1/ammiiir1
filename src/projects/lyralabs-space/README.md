## Overview

My personal portfolio. The rest of the site is conventional portfolio content; the differentiator is the splash: a Three.js-based, space-themed cinematic sequence with camera movement, particles, and transitions, choreographed across a coordinated animation/motion timeline. The engineering challenge was coordinating a complex real-time 3D sequence into a coherent timeline while maintaining acceptable runtime performance, which the splash was tuned and optimized for.

The project was built with my custom agentic development workflow as part of the engineering process.
