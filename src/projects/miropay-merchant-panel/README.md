# MiroPay — Merchant Panel

Merchant dashboard for the MiroPay payments platform.

- **Role:** Frontend Team Lead
- **Period:** 2025-04 – 2025-12
- **Relationship:** built at MIROTECH GROUP

## Overview

MiroPay is a payments platform with merchant and staff panels. I led the frontend side of the platform with a team of five frontend developers including myself: I defined and guided the overall application structure, reviewed the other developers' code, identified issues and asked developers to fix them, simplified or improved implementations where needed, and reviewed and merged frontend changes.

Because payment-gateway work was sensitive, I handled those parts directly rather than delegating them — including Stripe, regional and local gateways, bank-specific gateways, and cryptocurrency flows.

## Responsibilities & Contributions

- Led the overall frontend code structure and defined/guided the application structure
- Reviewed other frontend developers' code, identified issues, and guided fixes
- Simplified or improved implementations during review; reviewed and merged frontend changes
- Personally implemented the sensitive payment-gateway work: Stripe, regional/local gateways, bank-specific gateways, and cryptocurrency flows
