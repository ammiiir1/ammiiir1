# Doshell Co

Visually driven company and product catalog experience, with motion-driven presentation as a central part of the implementation.

- **Role:** Full-Stack Developer
- **Period:** 2019 – 2020
- **Relationship:** client work at Danak Corporation

## Overview

A company and product catalog for Doshell Co, served with SSR (Nuxt.js). The visual presentation was central to the project, not a finishing touch: I built a custom UI where animations, transitions, and motion-driven presentation carry the browsing experience, alongside the full-stack implementation of the catalog itself.

## Responsibilities & Contributions

- Full-stack implementation of the catalog experience (Nuxt.js SSR frontend with Node.js backend)
- Custom UI with animations, transitions, and motion-driven presentation as a core part of the experience
