# LyraLabs

**Period:** June 2026 – Present  
**Role:** Full-Stack Developer  
**Website:** lyralabs.space

## Overview

LyraLabs is my personal portfolio and experimental web platform, built to explore how engineering, motion, and interactive design can come together in a production web experience.

The project goes beyond a conventional developer portfolio. It combines a modern React/Next.js architecture with real-time 3D graphics, procedural particle systems, cinematic motion, and carefully designed interactive transitions.

## Technical Highlights

- Built with Next.js, React, TypeScript, Tailwind CSS, Three.js, React Three Fiber, GSAP, and Motion.
- Developed a cinematic WebGL introduction featuring custom camera choreography, particle systems, shaders, morphing effects, and procedural visual elements.
- Designed responsive experiences with separate performance considerations for desktop and mobile devices.
- Implemented performance optimizations around rendering, animation loops, scene lifecycle, LOD behavior, and WebGL resource management.
- Built the project using an agentic development workflow with specialized AI-assisted coding, auditing, motion review, and specification-driven development.
- Designed and implemented the complete product independently, from technical architecture and visual experimentation to deployment and production optimization.
