# dLabel

AI dataset annotation web application: videos are converted into image frames and annotators label them to prepare AI/model datasets.

- **Role:** Frontend Developer
- **Period:** 2021-05 – 2021-07
- **Relationship:** client work, Self-Employed / Freelance

## Overview

dLabel is tooling for AI dataset preparation. Clients upload videos, the backend converts them into image frames, and annotators annotate those frames to produce training datasets. I worked on the frontend, with my strongest contribution on the Project Manager page: a substantial UI redesign and restructuring of that interface, improving how annotation projects and frame-based work were presented and managed. Real-time features ran over WebSocket.

## Responsibilities & Contributions

- Major UI redesign and restructuring of the Project Manager page
- Improved the presentation and management of annotation projects and frame-based work
- Frontend work on the annotation workflow (the AI model itself was not part of my scope)
